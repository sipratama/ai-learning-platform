This is a behavioral UX contract, not a visual design or frontend implementation. AG02-01–AG02-05 are current explicit Product Owner decisions, separate from historical DP-01 evidence. A screen never presents local activity as official passing, and it must distinguish a Student's pinned published version from newer available versions. Numeric accessibility/performance targets remain FA-007 Open.

| State for UX-005 | Interactive asset loading; absent optional activity may be skipped only when policy says optional. | Invalid input or failure does not mark authoritative passing. | Interaction has non-color feedback, labels and keyboard operation; motion is not necessary to understand outcome. |

## 3. Interaction boundaries

- **Official versus local:** Student server-verified evidence and Guest local practice must be labeled differently wherever shown (UX-004–UX-009).
- **Pinned version:** A new publication may be visible as an update, but opening a currently enrolled Course continues its pinned version unless controlled migration succeeds (UX-003, UX-009, UX-012, UX-013).
- **Deferred scope:** Rule-based recommendations, AI grading/tutor, executable sandbox, broad gamification and payment interfaces are not MVP UX requirements.
- **Archive/revocation:** Normal archive/unpublish blocks new enrollment but preserves eligible existing pinned access. Exceptional revocation requires separate authorization and audit; no UI silently erases historical results (UX-003, UX-016).
- **Unresolved:** FA-006 controls retention; FA-007 controls quantitative accessibility/UX/performance targets; FA-008 controls operational targets. Exact protected prerequisite actions, Path curriculum migration, compatibility criteria and exceptional access-eligibility policy edges remain unspecified. UX-002, UX-003, UX-004, UX-013 must not imply permanent historical content access.
