## 1. Authority and test boundary

Sources: [DP-01 decisions](../DP-01/03-decision-registry.md), [DP-02 rules](../DP-02/02-domain-rules-and-invariants.md), [DP-03 architecture](../DP-03/06-architecture-decisions-and-traceability.md), [DP-04 SEC-001–024](../DP-04/02-authentication-authorization-and-security.md), [API contracts](../DP-04/01-api-contract-and-resource-design.md), and [operations](../DP-04/05-observability-reliability-and-runbooks.md). AG-04 conditionally approved its six v0.1.0 documents; these are test **plans**, with no execution or passing evidence. Use only authorized project tenants/environments and synthetic accounts. Production-safe checks require separate release authorization; no tests against external systems or real users. Record redacted request/result, affected owner state and artifact reference using the [evidence contract](01-test-strategy-and-risk-based-coverage.md#5-evidence-contract-and-acceptance-implications).

Severity below is **potential consequence if the control fails**, not an observed defect. `Hard` means a confirmed exploitable failure is a nonwaivable security/integrity/privacy No-Go; `Assess` means triage actual impact and disposition under [release criteria](05-release-evidence-and-go-no-go-criteria.md). GAP-dependent details are conditional and cannot be implemented or marked passed while open.

## 3. Privacy and release implications

FA-006 B and FA-006-B1 B require deletion or irreversible de-identification of *individual* Student-linked learning records, while truly anonymous aggregates may remain. Active data deletion targets 30 days from valid request, backup expiry 30 days, and minimized security audit retention 180 days unless legitimate legal obligation requires otherwise. Test legal exception as documented scope, not assumed blanket retention. Restore into isolated restricted state and verify suppression/replay before access is enabled. These targets are Product Owner policy, not a statutory claim.

Any unresolved Critical/High security blocker, unauthorized cross-Student access, privilege escalation, answer leakage, or personal-data exposure fails the hard gate. Noncritical security findings need owner, mitigation and documented disposition; ordinary performance/UX exceptions cannot waive security or integrity. [Functional scenarios](02-functional-integration-and-e2e-verification.md), [release model](05-release-evidence-and-go-no-go-criteria.md) and [traceability](06-verification-traceability-and-defect-management.md) are related. GAP-001/002/003/007 remain Open, AG-05 Not Approved, and no test result is asserted.
